FOZILBEK AI — TELEGRAM BOT
============================

1. Shu papkadagi config.py faylini Notepad bilan och.

2. Mana bu 2 qatorni to'ldir:

TELEGRAM_BOT_TOKEN = "BU_YERGA_BOTFATHER_TOKEN"
GEMINI_API_KEY = "BU_YERGA_GEMINI_API_KEY"

BotFather bergan tokenni birinchi joyga,
Gemini API keyni ikkinchi joyga yoz.

3. Saqla.

4. run.bat faylini ikki marta bos.

5. Telegramda botga /start yubor.

BUYRUQLAR:
-----------
/start
/help
/clear
/model

MUHIM:
-------
API tokenlaringni hech kimga yuborma.

Agar oldin Gemini API keyni internetga yoki birovga oshkor qilgan
bo'lsang, xavfsizlik uchun uni yangilab (rotate qilib) ol.

Bu versiya Telegram botning AI backend qismidir.
Sening HTML "Cosmic Intelligence" dizayning Telegram chat ichida
to'g'ridan-to'g'ri ishlamaydi. Keyingi bosqichda HTML interfeysni
Telegram Web App qilib ulash mumkin.

Bot polling orqali ishlaydi, shuning uchun kompyuteringda
run.bat ishlayotgan paytda bot online bo'ladi.
